# اپلیکیشن تعزیه (BookApp)

## ساختار جریان اپلیکیشن
ورود (Login) -> منوی اصلی (لیست تعزیه‌ها / درباره برنامه / تنظیمات / ورژن)
-> فهرست زمینه‌ها (اصفهان، تهران، میرعزا و ...)
-> فهرست تعزیه‌ها (عاشورا، بازار شام و ...)
-> فهرست نقش‌ها (شمر، امام، یزید و ...)
-> فهرست بخش‌ها (ورود، ساقی‌نامه، شهادت و ...)
-> متن اشعار همان بخش

## چگونه پروژه را باز کنم؟
1. Android Studio (نسخه Iguana یا جدیدتر) را نصب کنید.
2. پوشه BookApp را با گزینه Open در Android Studio باز کنید.
3. صبر کنید Gradle Sync تمام شود.
4. روی دکمه Run بزنید تا روی گوشی یا شبیه‌ساز نصب شود.

با اولین اجرا، برنامه به‌طور خودکار داده‌های نمونه از فایل‌های JSON داخل پوشه‌ی
app/src/main/assets/content/ را به ترتیب نام فایل در دیتابیس داخلی (Room/SQLite) وارد می‌کند.

## چطور محتوای واقعی (فایل ورد) را اضافه کنم؟

### روش پیشنهادی: تبدیل Word به JSON و افزودن خودکار
1. فایل ورد خود را طبق قرارداد زیر با استایل‌های Heading بنویسید (در Word از پنل Styles استفاده کنید):
   - Heading 1 = عنوان زمینه (اصفهان، تهران، میرعزا و ...)
   - Heading 2 = عنوان تعزیه (عاشورا، بازار شام و ...)
   - Heading 3 = عنوان نقش (شمر، امام، یزید و ...)
   - Heading 4 = عنوان بخش (ورود، ساقی‌نامه، شهادت و ...)
   - پاراگراف‌های معمولی زیر Heading 4 = متن اشعار همان بخش

2. اسکریپت پایتون را با فقط یک ورودی اجرا کنید (بدون مشخص‌کردن خروجی):
   pip install python-docx --break-system-packages
   python scripts/docx_to_json.py my_new_majles.docx

   اسکریپت خودش یک فایل تازه و شماره‌دار (مثلاً 002_my-new-majles.json) داخل
   app/src/main/assets/content/ می‌سازد.

3. همین یک فایل جدید را commit/push کنید. **نیازی به لمس یا جایگزینی فایل‌های
   قبلی نیست** — برنامه در اجرای بعدی، فقط فایل‌های جدید پوشه‌ی content را
   شناسایی و به دیتابیس اضافه می‌کند (بدون پاک‌شدن محتوای قبلی، حتی برای
   کاربرانی که اپ را قبلاً نصب کرده‌اند و فقط بروزرسانی می‌گیرند).

4. اگر زمینه/تعزیه/نقشی که در فایل جدید هست از قبل با همان عنوان وجود داشته
   باشد (مثلاً افزودن نقش تازه به یک تعزیه‌ی موجود)، برنامه آن را به همان
   مورد موجود اضافه می‌کند، نه اینکه یک نسخه‌ی تکراری بسازد. بخش‌های
   (sections) جدید همیشه به‌ترتیب، انتهای بخش‌های موجود همان نقش اضافه می‌شوند.

### اگر چند فایل ورد دارید
اسکریپت را برای هر فایل جدا اجرا کنید؛ هرکدام یک فایل JSON مستقل در content/ می‌سازد. لازم نیست آن‌ها را دستی ادغام کنید.

## نکته درباره صفحه ورود (Login)
اگر از تنظیمات، رمز عبوری تعیین نکرده باشید، ورود فقط با نام کاربری (بدون بررسی رمز) انجام می‌شود.
برای تعیین یا تغییر رمز عبور، از منوی «تنظیمات» گزینه‌ی «تغییر رمز عبور» را استفاده کنید.

## ساختار پوشه‌ها
BookApp/
  app/src/main/java/com/example/bookapp/
    MainActivity.kt
    data/            (Entity ها، DAO ها، دیتابیس Room)
    ui/
      AppNavigation.kt   (مسیریابی بین صفحات)
      screens/           (صفحات ورود، منوی اصلی، فهرست عمومی، متن، درباره/تنظیمات/ورژن)
  app/src/main/assets/content/           (فایل‌های JSON محتوای تعزیه، به‌ترتیب نام بارگذاری می‌شوند)
  scripts/docx_to_json.py                (تبدیل Word به JSON، با افزودن خودکار به content/)
