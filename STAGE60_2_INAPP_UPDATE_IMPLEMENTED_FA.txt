Stage60.2 - تکمیل بروزرسانی داخل برنامه

1. منطق بروزرسانی داخل خود APK باقی می‌ماند و به مرورگر وابسته نیست.
2. نسخه Admin فقط APK مربوط به Admin را از Manifest انتخاب می‌کند.
3. نسخه Viewer/Public فقط APK مربوط به Viewer را از Manifest انتخاب می‌کند.
4. GitHub Actions در هر Build فایل update.json را خودکار می‌سازد.
5. update.json همراه هر دو APK در GitHub Release منتشر می‌شود.
6. دانلود داخل برنامه انجام می‌شود و APK قبل از نصب از نظر package و versionCode بررسی می‌شود.
7. فایل دانلودشده ناقص (.part) قابل نصب نیست و APK معتبرِ قبلی در صورت امکان دوباره استفاده می‌شود.
8. بخش‌های نامرتبط برنامه تغییر داده نشده‌اند.
