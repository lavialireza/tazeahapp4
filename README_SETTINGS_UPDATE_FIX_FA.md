# اصلاح تنظیمات و زنجیره بروزرسانی آزمایشی

## تغییرات این مرحله
- گزینه‌های متنی «کوچک/متوسط/بزرگ/خیلی بزرگ» حذف شدند و نوار سایز فونت باقی ماند.
- پیش‌نمایش واحد بعد از «فونت متن» قرار گرفت و اندازه فونت، نوع فونت، فاصله خطوط، حالت تیره و رنگ تم را در ظاهر پیش‌نمایش منعکس می‌کند.
- بخش «فاصله خطوط متن» در کنار تنظیمات مربوط به متن باقی ماند.
- «روشن نگه‌داشتن صفحه» در بخش بالایی تنظیمات باقی/منتقل شد.
- «تغییر رمز عبور» قبل از «تم رنگی» و «بروزرسانی‌ها» قرار گرفت.
- «تم رنگی» بعد از رمز و قبل از بروزرسانی‌ها قرار گرفت.

## مشکل نصب بروزرسانی APK
Buildهای Debug قبلی GitHub Actions روی هر runner با کلید Debug متفاوت امضا می‌شدند؛ بنابراین APK جدید با APK نصب‌شده قبلی از نظر امضای بسته متفاوت بود و اندروید پیام تداخل بسته می‌داد.

برای buildهای Debug آزمایشی از این مرحله، یک کلید ثابت داخل `ci/tazieh-test-signing.jks` استفاده شده است تا buildهای بعدی همان flavor قابل بروزرسانی باشند.

**نکته:** APKهای قبلی که با کلید قدیمی CI نصب شده‌اند، یک‌بار باید حذف و نسخه جدید همین مرحله نصب شود. پس از آن، buildهای Debug بعدی با همین کلید ثابت باید به‌صورت بروزرسانی نصب شوند.

این کلید فقط برای تست داخلی است و برای انتشار رسمی/Play Store استفاده نشود. انتشار رسمی باید با Release Keystore ثابت و خصوصی انجام شود.
